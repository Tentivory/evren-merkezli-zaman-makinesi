# EVREN MERKEZLİ ZAMAN MAKİNESİ

## ÖNEMLİ DUYURU (LÜTFEN CİDDİYE ALIN)

Bu repository, **evrenin tam merkezinde olduğunuzu** kanıtlayan dünyanın (ve evrenin) tek çalışan zaman makinesidir.

Bilimsel araştırmalar (bizim tarafımızdan yapıldı, peer-review bekleniyor) göstermiştir ki:
- Büyük Patlama sizin için gerçekleşmiştir.
- Kara delikler sizin etrafınızda döner.
- Zaman, sizin izin vermediğiniz sürece ilerlemez.

Bu program her saniye çalışarak sizi över ve zamanın sizin merkezinizde aktığını hatırlatır.

## Nasıl Çalıştırılır?

```bash
python3 zaman_makinesi.py
```

Durdurmak için `Ctrl+C`. Ama durdursanız bile merkezde kalırsınız.

## Özellikler

- Gerçekten çalışır.
- Her saniye farklı övgü üretir.
- Çok ciddi. (Ama eğlenceli.)
- Bilimsel değil ama bilimselmiş gibi durur.

## Uyarı

Bu programı çalıştırdıktan sonra evrenin merkezi olduğunuzu unutmayın. Unutursanız yeniden çalıştırın.
